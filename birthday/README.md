# 우리 가족 생일

음력 생일을 **올해의 양력 날짜로 자동 변환**해 보여주는 가족 생일 앱입니다.
설치가 필요 없는 **PWA**라 갤럭시·아이폰에서 브라우저로 열고 “홈 화면에 추가”하면 앱처럼 씁니다.

## 기본 화면

구성원 카드가 **다가오는 생일 순**으로 정렬됩니다. 각 카드에는

- 사진(첨부한 경우) 또는 이름 첫 글자
- 이름 · 관계
- **올해 양력 생일** 날짜와 요일, D-day
  - 올해 생일이 이미 지났으면 다음 생일을 크게, 올해 날짜는 아래에 함께 표시
  - 음력 12월생처럼 올해 음력 생일이 내년 양력으로 넘어가면 그 사실이 라벨에 드러납니다
- 설정에 입력한 생년월일 정보 (음/양력, 윤달, 태어난 시각)
- 양력 생년월일, 태어난 해의 간지, 만 나이

## 설정

| 기능 | 설명 |
| --- | --- |
| 생년월일 입력·수정 | 구성원마다 **음력 / 양력**을 골라 연·월·일 입력, 음력이면 윤달 선택 |
| 구성원 추가 | 이름과 관계를 넣어 얼마든지 추가 (삭제도 가능) |
| 사진 첨부 | 휴대폰 사진첩·카메라에서 골라 첨부하면 기본 화면 카드에 나타납니다 |
| 태어난 시각 | 십이지시(자시·인시·오시·신시…)와 정확한 시:분을 함께 기록 |
| 생일 알림 | 한 달 전 / 1주일 전 / 하루 전 / 1시간 전 / 당일 / 직접 설정(N일·시간·분 전) |
| 알림음 | 생일 축하 멜로디 · 딩동 차임 · 종소리 · 마림바 · 전자음 · 무음 (미리듣기 지원) |
| 캘린더 등록 | 앞으로 6년치 생일을 `.ics` 파일로 내려받아 휴대폰 캘린더에 넣기 |
| 백업 / 복원 | 모든 정보를 JSON 파일로 저장하고 되돌리기 |

편집 화면에서는 입력하는 즉시 **양력 생년월일과 올해 양력 생일**이 계산되어 아래에 표시됩니다.

## 알림에 대해

- 앱이 켜져 있거나 백그라운드에 남아 있으면 앱이 직접 알림을 띄웁니다.
- 앱을 완전히 종료하면 웹 앱은 스스로 깨어날 수 없습니다.
  그래서 **`.ics` 캘린더 등록**을 함께 제공합니다. 한 번 등록해 두면 앱과 무관하게
  휴대폰 캘린더가 알림을 울립니다. 이 방식을 권합니다.
- `.ics` 안의 알림 시각은 설정한 “알림 기준 시각”과 미리 알림 항목을 그대로 반영합니다.

## 음력 변환

음력↔양력 변환은 한국천문연구원(KASI) 자료를 담은
[korean-lunar-calendar](https://github.com/usingsky/korean_lunar_calendar_js) (MIT)를
`lunar.js` 로 내장해 사용합니다. **음력 1000년 ~ 2050년 11월** 범위를 지원하므로
2050년까지의 생일을 계산할 수 있습니다.

변환 시 다음을 자동으로 처리합니다.

- 그 해에 음력 30일이 없는 달이면 **29일(그믐)** 로 맞춤
- 설정한 윤달이 그 해에 없으면 **평달**로 계산 (카드에 안내 표시)
- 양력 2월 29일생은 평년에 **2월 28일**로 맞춤

## 휴대폰에서 사용하기

1. GitHub Pages 등으로 이 폴더를 서빙합니다. (`Settings > Pages` 에서 브랜치 지정)
2. 휴대폰 브라우저에서 `…/birthday/` 주소로 접속합니다.
3. Samsung Internet·Chrome 메뉴 → **홈 화면에 추가**, 사파리는 **공유 → 홈 화면에 추가**.
4. 홈 화면 아이콘으로 실행하면 주소창 없는 앱 화면으로 열립니다.

로컬에서 확인하려면 저장소 최상위에서:

```bash
python3 -m http.server 8080
# http://localhost:8080/birthday/
```

`file://` 로 열면 서비스 워커와 일부 기능이 동작하지 않습니다.

## 파일 구성

- `index.html` — 화면 구조
- `styles.css` — 스타일
- `app.js` — 음/양력 계산, 알림, 설정, `.ics` 생성
- `lunar.js` — 내장 음력 변환 라이브러리 (MIT)
- `manifest.webmanifest` — PWA 매니페스트
- `sw.js` — 서비스 워커 (오프라인 캐시)
- `icon.svg` — 앱 아이콘

## 저장 위치

모든 정보(사진 포함)는 **휴대폰 브라우저 저장소(localStorage)** 에만 저장되며 서버로 전송되지 않습니다.
브라우저 데이터를 삭제하면 함께 지워지니 설정의 **백업 파일 저장**을 가끔 이용하세요.
