# 운동 타이머 (Bridge Timer)

브릿지 등 반복 운동을 위한 음성 안내 타이머입니다. 삼성 갤럭시 스마트폰에서 Samsung Internet 또는 Chrome으로 열어 사용하며, **PWA**로 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

## 기본값
- 운동: 브릿지
- 3세트 × 10회 × 30초
- 회차 사이 휴식 7초, 세트 사이 휴식 12초
- 시작 준비 5초, 격려 멘트 켜짐, 비프음 켜짐

## 주요 기능
- 30초 유지 → 휴식 → 반복 자동 진행
- 남은 시간 링 + 큰 숫자 표기
- **한국어 음성 안내**: 회 시작/종료, 카운트다운(3·2·1), 절반 지점, 세트 종료, 완료
- 사용 가능한 시스템 음성 중 **여러 음성 선택 가능** (`설정 > 음성 선택`)
- 말하기 속도/음성 높이 조절
- **격려 멘트** 편집/추가/삭제 (한 줄에 하나씩)
- 운동 종류/세트 수/회수/시간을 직접 선택하거나 입력
- 화면 꺼짐 방지 (Wake Lock)
- 오프라인 동작 (Service Worker)

## 배포/실행 (권장)
정적 파일이므로 GitHub Pages 또는 로컬 서버로 서빙하세요. (파일 프로토콜 `file://` 로는 Service Worker 및 일부 브라우저 정책이 동작하지 않습니다.)

로컬 확인:
```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

GitHub Pages 배포 시 저장소의 `Settings > Pages` 에서 브랜치를 지정한 뒤,
갤럭시에서 접속 → Samsung Internet 메뉴 → "홈 화면에 추가" → 앱 아이콘 실행.

## 파일 구성
- `index.html` — UI
- `styles.css` — 스타일
- `app.js` — 타이머/음성/설정 로직
- `manifest.webmanifest` — PWA 매니페스트
- `sw.js` — 서비스 워커 (오프라인 캐시)
- `icon.svg` — 앱 아이콘

## 치환 변수
멘트 편집 시 다음 변수를 사용할 수 있습니다.
- `{exercise}` 운동 이름
- `{set}` / `{sets}` 현재/전체 세트
- `{rep}` / `{reps}` 현재/전체 회수
- `{sec}` 안내 대상 시간(초)
