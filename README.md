# 운동 타이머 (Bridge Timer)

브릿지 등 반복 운동을 위한 음성 안내 타이머입니다. 삼성 갤럭시 스마트폰에서 Samsung Internet 또는 Chrome으로 열어 사용하며, **PWA**로 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

## 기본값
- 운동: 브릿지
- 3세트 × 10회 × 30초
- 회차 사이 휴식 7초, 세트 사이 휴식 12초
- 시작 준비 5초, 격려 멘트 켜짐, 비프음 켜짐

## 주요 기능
- 30초 유지 → 휴식 → 반복 자동 진행
- 남은 시간 링 + 큰 숫자 표기
- **한국어 음성 안내**: 회 시작/종료, 카운트다운(3·2·1), 절반 지점, 세트 종료, 완료
- 사용 가능한 시스템 음성 중 **여러 음성 선택 가능** (`설정 > 음성 선택`)
- 말하기 속도/음성 높이 조절
- **격려 멘트** 편집/추가/삭제 (한 줄에 하나씩)
- 운동 종류/세트 수/회수/시간을 직접 선택하거나 입력
- 화면 꺼짐 방지 (Wake Lock)
- 오프라인 동작 (Service Worker)

## 배포/실행 (권장)
정적 파일이므로 GitHub Pages 또는 로컬 서버로 서빙하세요. (파일 프로토콜 `file://` 로는 Service Worker 및 일부 브라우저 정책이 동작하지 않습니다.)

로컬 확인:
```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

GitHub Pages 배포 시 저장소의 `Settings > Pages` 에서 브랜치를 지정한 뒤,
갤럭시에서 접속 → Samsung Internet 메뉴 → "홈 화면에 추가" → 앱 아이콘 실행.

## 파일 구성
- `index.html` — UI
- `styles.css` — 스타일
- `app.js` — 타이머/음성/설정 로직
- `manifest.webmanifest` — PWA 매니페스트
- `sw.js` — 서비스 워커 (오프라인 캐시)
- `icon.svg` — 앱 아이콘

## 치환 변수
멘트 편집 시 다음 변수를 사용할 수 있습니다.
- `{exercise}` 운동 이름
- `{set}` / `{sets}` 현재/전체 세트
- `{rep}` / `{reps}` 현재/전체 회수
- `{sec}` 안내 대상 시간(초)

# 🎮 졸라맨 런 (`jollaman/`)

졸라맨이 왼쪽에서 오른쪽으로 달리며 점프·슬라이드로 장애물을 피하고 아이템을 모으는 **아케이드 횡스크롤 러너**입니다.
빌드 없이 `jollaman/index.html` 을 열면 바로 실행됩니다 (위의 로컬 서버 실행 후 `http://localhost:8080/jollaman/`).

## 조작
| 동작 | 키보드 | 터치 |
| --- | --- | --- |
| 점프 / 2단 점프 (길게 누르면 더 높이) | `SPACE` `↑` `W` `Z` | 화면 탭 |
| 슬라이드 (공중에선 급강하) | `↓` `S` `X` 꾹 | 왼쪽 아래 버튼 |
| 일시정지 / 소리 | `P`·`ESC` / `M` | 오른쪽 위 버튼 |
| 캐릭터 상점 | `C` (방향키 선택, `SPACE` 구매/장착) | 왼쪽 위 SHOP 버튼 |

## 게임 요소
- **적**: 슬라임(밟아서 처치), 네온 박쥐(슬라이드로 피하거나 밟기), 가시(점프로 회피), 구덩이(낙하 시 목숨 -1)
- **아이템**: 코인, 💎 보석(+500), ⭐ 스타(무적 7초), 🧲 자석(10초), x2 점수 2배(12초), ❤️ 하트(1UP)
- **콤보**: 코인·처치를 끊김 없이 이어가면 점수 배율 최대 x5, 코인 효과음 음높이가 점점 올라감
- **피버 타임**: 게이지를 채우면 6초간 무적 + 가속 + 자석 + 점수 2배, 구덩이 위로 무지개 다리
- **스테이지**: 600m마다 스테이지 업 → 속도 증가, 배경 테마·BGM 템포/조성 변경 (5가지 테마 순환)
- **보스전**: 3스테이지마다 보스(킹 슬라임 → 메가 슬라임 → 헬 슬라임) 등장
  - 공격 패턴: 침 뱉기(낮은 탄은 점프, 높은 탄은 슬라이드), 내려찍기 충격파(점프), 돌진(점프해서 머리를 밟으면 데미지!)
  - 보스를 쓰러뜨리면 보너스 점수 + 코인 비 + 하트. 보스전 동안은 거리가 멈춤
- **캐릭터 상점** (타이틀·게임오버에서 `C` 또는 SHOP 버튼)
  - 판마다 모은 코인이 지갑에 쌓이고, 8종 스킨을 구매·장착 (네온 블루, 쿨가이, 닌자, 슈퍼 히어로, 마법사, 황금 졸라맨, 무지개 전설 등)
- 코인 100개마다 1UP, 로컬 **TOP 5 랭킹** 저장
- 사운드는 전부 WebAudio로 합성한 칩튠 (BGM + 효과음), CRT 스캔라인 연출
